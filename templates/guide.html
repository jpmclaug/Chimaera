01 // System Architecture & Multi-Vendor Engines

[ SEC:ARCH ]

Chimaera is a high-density, tactical MTG single-card market surveillance system. It continuously aggregates pricing and inventory telemetry across three distinct commercial endpoints, calculates real-time arbitrage against user-defined target thresholds, and dispatches automated deal notifications.

Engine 01 REST API

Scryfall / TCGplayer

Powers instant card name autocomplete, high-resolution artwork resolution, all printing classifications, and retrieves authoritative TCGplayer Market USD prices for Non-foil, Foil, and Etched finishes.

• Finish variant matching
• "Any Version" lowest-price scanner
Engine 02 BinderPOS / JSON

Mighty Meeple

Directly queries MightyMeeple.com's Shopify & BinderPOS inventory system (/search/suggest.json & /products/{handle}.js). Scans live stock availability and condition tiers (Near Mint NM vs Lightly Played LP).

• Real-time in-stock verification
• Direct product checkout links
Engine 03 Finding API + Scraper

eBay Market Singles

Scans live eBay Buy-It-Now (BIN) single listings. Supports official eBay Developer Finding API credentials with an automated resilient HTML scraping fallback engine for zero-config deployments.

• Filtered Buy-It-Now queries
• Outlier price sanitization

02.2 Target Registration Protocol (Add Card Modal 0x4A)

Clicking the crimson Acquire Target button in the top navigation opens the registration protocol:

STEP 1
Search Autocomplete
Type any card name (e.g. The One Ring, Force of Will, Mana Crypt). Scryfall debounced lookup returns matching card nomenclature instantly.
STEP 2
Select Version Scope (Any Version vs Specific Printing)
Any Version (Default): Evaluates deals against the absolute lowest live price across every printing of that card in existence. Perfect for commander players wanting the cheapest playable copy.
Specific Printing: Select a particular set (e.g. Limited Edition Alpha [LEA] or Double Masters [2XM]) to strictly monitor prices for that exact printing.
STEP 3
Set Target Acquisition Threshold with 1-Click Intelligence Presets
Chimaera automatically calculates the current market reference price and offers one-click buttons to set your target to Great Deal (-20%), Good Deal (-10%), or Market Price (100%). You can also manually type any custom target dollar threshold.
STEP 4
Immediate Multi-Vendor Ingestion
Clicking "Add to Watchlist" writes the asset to the database and immediately executes a live scan across TCGplayer, Mighty Meeple, and eBay.

02.3 Bulk Target Acquisition Protocol (Batch Registration 0x4B)

Clicking the + Bulk Add button in the top navigation opens the batch acquisition protocol.

// SEMICOLON (;) DELIMITED SYNTAX

Simic Growth Chamber; Tangled Islet; Rimewood Falls; Evolving Wilds; Lush Oasis; Thornwood Falls; Lonely Sandbar; Tranquil Thicket; Bant Panorama
Scryfall Collection API

Automated Target Presets
Optionally apply Good Deal (-10%) or Great Deal (-20%) target price thresholds automatically to all imported targets.
Immediate Multi-Vendor Sweep
Ingests cards into your registry and immediately executes live market surveillance across TCGplayer, Mighty Meeple, and eBay.

02.5 Priority Deals Dashboard & Arbitrage Evaluation (`/deals`)

Whenever any monitored vendor's in-stock price drops to or below your configured Target Threshold (Lowest In-Stock Price ≤ Target Price):

03 // How to Update Prices from the Site Itself (Web UI)

[ SEC:POLL-SITE ]

Chimaera provides multiple granular ways to trigger price updates directly from within the web interface without restarting the server or touching a terminal:

[ METHOD 1: TOP NAVIGATION BAR ] POST /api/watchlist/refresh-all

"Poll Watchlist" Full Surveillance Sweep

Click the "Poll Watchlist" button in the top navigation bar at any time. The icon will spin while the backend scans all cards in your database across TCGplayer, Mighty Meeple, and eBay in sequence. As soon as the sweep completes, the page automatically refreshes and displays the new prices, deal badges, and sends Discord notifications for newly identified deals.

[ METHOD 2: INDIVIDUAL TARGET CARD ] POST /api/watchlist/refresh/<id>

Single Target "Poll" Button

On any card card in either the Registry (/) or Priority Deals (/deals) view, click the "Poll" button located in the card footer. This performs a fast, targeted refresh for only that single card across all 3 providers without having to rescan the entire watchlist.

[ METHOD 3: CADENCE MODAL ] POST /api/worker/trigger

Surveillance Cadence Modal "⚡ Poll Now"

Click the "Cadence" button in the top navigation bar to open the Surveillance Protocol configuration modal (CONFIG // 0x7E). Click the "⚡ Poll Now" button. This immediately runs a full watchlist scan, records the timestamp and telemetry into the database, and flags any background daemon workers to synchronize.

[ METHOD 4: AUTOMATED INTERVAL ] POST /api/settings/cadence

Automated Background Cadence Configuration

Inside the Cadence modal, select your preferred surveillance interval from the dropdown: Every 15 min (0.25h), 30 min, 1h, 2h, 4h, 6h (Default), 12h, or 24h. Make sure "Enable Automated Background Surveillance" is checked and click "Save Cadence". The standalone background worker (worker.py) continuously reads this interval directly from the database and automatically adjusts its timer on the fly!

[ METHOD 5: TARGET ACQUISITION ] POST /api/watchlist/add

Auto-Refresh on Card Creation

Whenever a new card is registered via the "Acquire Target" modal, the system immediately executes a live poll across Scryfall, Mighty Meeple, and eBay before redirecting you back to the registry, ensuring brand-new cards always display live market data from second one.

04 // How to Update Prices from GitHub Actions (Serverless Cloud Automation)

[ SEC:ACTIONS ]

Chimaera includes a turnkey GitHub Actions workflow (.github/workflows/surveillance_worker.yml) that runs price surveillance sweeps in the cloud on a recurring cron schedule or on-demand, without needing an active computer or paid 24/7 server.

// GITHUB ACTIONS WORKFLOW PIPELINE
[ GitHub Scheduler (Cron) / Manual Trigger ] → [ Ephemeral Ubuntu Runner ] → [ Connects to Neon PostgreSQL ] → [ Scans Scryfall, Mighty Meeple, eBay ] → [ Updates DB & Dispatches Discord Alerts ] → [ Exits Cleanly ]
REQUIRED STEP 1

Configure GitHub Repository Secrets

For the GitHub Actions worker to connect to your database and send Discord alerts, you must add your environment secrets to your GitHub repository:

  1. Go to your repository on GitHub: https://github.com/<your-username>/<your-repo>
  2. Click Settings (top tab) → Secrets and variables (left sidebar) → Actions.
  3. Click the green "New repository secret" button for each of the following:
Secret Name Description Example Value
DATABASE_URL Your Neon Serverless PostgreSQL URI (Required) postgresql://neondb_owner:npg_xxx@ep-xyz.us-east-2.aws.neon.tech/neondb?sslmode=require
DISCORD_WEBHOOK_URL Discord channel webhook for deal alerts (Optional) https://discord.com/api/webhooks/123456/abcdef...
EBAY_APP_ID eBay Developer App ID for Finding API (Optional) YourAppId-Production
AUTOMATION

Automated Scheduled Sweeps (Cron)

By default, the workflow is scheduled to trigger every 6 hours automatically:

schedule:
  - cron: '0 3,9,15,21 * * *'  # Runs at 03:00, 09:00, 15:00, 21:00 UTC (11pm, 5am, 11am, 5pm EDT)

You can adjust this schedule anytime by editing .github/workflows/surveillance_worker.yml in your repository.

MANUAL TRIGGER

Trigger Price Update via GitHub Web UI (`workflow_dispatch`)

You can trigger an immediate price sweep from any phone, tablet, or browser using GitHub's web interface:

  1. Navigate to your repository on GitHub.
  2. Click the Actions tab at the top of the repository.
  3. In the left sidebar, click "Chimaera Market Surveillance Worker".
  4. Click the "Run workflow" dropdown button on the right.
  5. Select branch main and click the green "Run workflow" button.
  6. Click the newly created run to watch live step-by-step logs of every card scanned and deal detected.
CLI TRIGGER

Trigger Price Update via GitHub CLI (`gh`)

If you use the official GitHub CLI tool, you can trigger the cloud worker with a single command from your terminal:

gh workflow run surveillance_worker.yml

05 // Standalone Worker Daemon & Command Line Options (`worker.py`)

[ SEC:WORKER ]

Chimaera includes an independent worker process (worker.py) that can be run on a local machine, VPS, Docker container, or Kubernetes cluster alongside or separate from the web application:

// MODE 1: CONTINUOUS SURVEILLANCE DAEMON
python worker.py

Runs continuously in the background, syncs worker heartbeat telemetry, detects UI cadence changes dynamically from the database, and sweeps prices on schedule.

Windows Launcher: .\start_worker.ps1 or start_worker.bat
// MODE 2: SINGLE SWEEP CRON RUN
python worker.py --once

Executes exactly one full surveillance sweep across all targets, commits updated prices to the database, dispatches deal alerts to Discord, and exits immediately.

Ideal for Windows Task Scheduler, Linux Cron, or AWS Lambda.
Command Line Flag Reference
--once : Run 1 scan cycle and exit immediately.
--interval <hours> : Override database polling interval (e.g. --interval 1.5).
--no-notify : Suppress Discord deal webhook dispatches during scan.
--verbose : Enable detailed debug-level logging output.

07 // Tactical Troubleshooting & Diagnostics Playbook

[ SEC:DIAG ]
// 1. Neon PostgreSQL Connection Drops / Auto-Suspend

Neon serverless databases automatically sleep when inactive. Chimaera is configured with pool_pre_ping=True and pool_recycle=300 in SQLAlchemy, preventing stale connection errors upon wake-up. Ensure your DATABASE_URL includes ?sslmode=require.

// 2. Discord Webhooks Not Triggering

Verify that DISCORD_WEBHOOK_URL is correctly set in .env or GitHub Secrets.

// 3. Scryfall Autocomplete or Rate Limits

Scryfall API requests are debounced on the client (250ms) and throttled by provider classes in compliance with Scryfall's 50–100ms rate guidelines.

// 4. Port Conflict on Windows

If port 5050 is already occupied by a previous session, execute .\stop_app.ps1 or stop.bat to gracefully terminate existing Python processes and free port 5050.
